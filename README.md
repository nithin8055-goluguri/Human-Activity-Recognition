# Human Activity Recognition System

## Overview

The Human Activity Recognition (HAR) System is a Machine Learning-based project designed to identify and classify human activities such as walking, sitting, standing, and laying using sensor and activity data.

## Features

* Activity Classification
* Data Collection and Processing
* Machine Learning Model Training
* Real-Time Activity Prediction
* Data Analysis and Visualization

## Technologies Used

* Python
* NumPy
* Pandas
* Scikit-Learn
* Machine Learning

## Project Files

* app.py – Main application
* train_model.py – Model training script
* generate_dataset.py – Dataset generation
* model.pkl – Trained machine learning model
* scaler.pkl – Data scaler
* label_encoder.pkl – Label encoder

## Future Improvements

* Deep Learning Models
* Mobile Integration
* Real-Time Monitoring Dashboard
